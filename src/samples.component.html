Small, complete apps, each built with the pieces the lessons teach. Open one and use it.

Todo list

A task list with priorities and filters, in this app's own colours. Add what needs doing from the plus at the top, tick it off as you go, and watch the day clear. Your tasks stay on this device.

Internet of Things Sample

A small smart home that lives in this app: a card for each room, a switch for every device, some devices on a timer, and a short history of what changed. The switches change this page only. No real device is controlled.

Alarm

One alarm with a time wheel, repeat days and a title, in this app's own colours. It rings on its page while the app is open. No notification and no sound file: the simple version.

Every sample on this page was built with Rangular, and so was this entire app: each screen began as Angular code and was compiled by the Rangular framework into the React Native app you are holding.
