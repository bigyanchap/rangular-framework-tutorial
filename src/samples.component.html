Small, complete apps, each built with the pieces the lessons teach. Open one and use it.

Breakout

The Atari classic: a paddle, a ball, and six rows of shiny bricks to clear. Real bounce physics, angle off the paddle, three lives, drawn and animated entirely with bindings.

Todo list

A task list with priorities, filters and a progress header. Add what needs doing, tick it off as you go, and watch the day clear. Your tasks stay on this device.

Every sample on this page was built with Rangular, and so was this entire app: each screen began as Angular code and was compiled by the Rangular framework into the React Native app you are holding.
