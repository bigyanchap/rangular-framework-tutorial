Small, complete apps, each built with the pieces the lessons teach. Open one and use it.

Alarm

A working alarm clock. Pick a time, switch it on, and it rings with its tone: on this screen while the app is open, and as a system notification when it is not.

Platformer

A small Mario style platform game: run, jump, gather coins, dodge the walkers, and reach the flag. One level, drawn and animated entirely with bindings.

Habit tracker

A daily checklist for the habits you choose. Tick each one off as the day goes, and start fresh tomorrow. Your list and your ticks stay on this device.

Every sample on this page was built with Rangular, and so was this entire app: each screen began as Angular code and was compiled by the Rangular framework into the React Native app you are holding.
